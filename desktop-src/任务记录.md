# 自动剪辑桌面版 V16 开发记录

## 目标

- 双击 `自动剪辑.exe` 打开管理界面。
- 不使用 Python，不弹出 PowerShell 或 CMD 黑框。
- 打包 .NET 8 self-contained x64 运行时，目标电脑无需安装 .NET。
- 复用已验证的 FFmpeg、Whisper、OpenCC、字幕和监控脚本，减少迁移风险。

## 已完成

- 建立独立 V16 发布目录，保留 V15 不改动。
- 新增原生 WinForms 管理界面：监控控制、配置保存、自检、日志和目录打开。
- 子进程使用隐藏窗口启动，桌面程序捕获日志输出。
- 图片动效改为按时长计算：30 秒图片约 15% 缩放，避免看似静止。

## 验证项

- 编译为 self-contained x64。
- 环境自检可从桌面程序启动。
- 监控脚本可无窗口启动、停止。
- 配置修改后可被 `config.ps1` 正确读取。
- 10 秒测试可从桌面程序启动。
- 30 秒单图动效实际输出为 1080x1920、30 FPS、900 帧。
