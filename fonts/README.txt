便携字体说明

1. 字幕设置器会读取 Windows 系统字体以及本目录和子目录中的 TTF、OTF、TTC 字体。
2. 可在“字体管理”页面批量导入字体，导入后无需安装到 Windows。
3. 复制整套程序到另一台电脑时，本目录中的字体会一起生效。
4. NotoCJK 目录内附带 Noto Sans CJK SC 和 Noto Serif CJK SC，授权文件为 LICENSE.txt。
5. Handwriting 目录内附带 Ma Shan Zheng、Liu Jian Mao Cao、Long Cang、ZCOOL KuaiLe 四套中文仿手写字体，每套字体的 OFL 授权文件保存在同一目录。
6. 自行导入其他字体前，请确认字体文件允许用于当前用途。
